# تحليل مبيعات متجر إلكتروني سعودي | Saudi E-commerce Sales Analysis

مشروع تحليل بيانات متكامل لمتجر إلكتروني سعودي، يمثل إتمام المرحلة الأولى من مسار الذكاء الاصطناعي - منصة سطر.

### 🎯 هدف المشروع
مساعدة صاحب متجر إلكتروني في السعودية على فهم:
- أي المدن تحقق أعلى مبيعات؟
- ما هي المنتجات الأكثر ربحاً؟
- ما هي طرق الدفع المفضلة للعملاء السعوديين؟
- متى مواسم الذروة؟

### 🧹 ما تم إنجازه في التنظيف
- البيانات الأصلية: 1220 صف
- حذف المكرر: 20 صف → 1200 صف
- حذف الأسعار السالبة والصفر: 15 صف
- معالجة القيم المفقودة:
    - CustomerID: ملء بـ Unknown
    - Price: ملء بمتوسط سعر نفس المنتج groupby(Product).mean()
- إنشاء أعمدة جديدة: Total, Month, DayName

### 📊 أهم النتائج
1. الفئة الأعلى ربحاً: الإلكترونيات (جوال 【entity-سامسونج¦canonical_name=سامسونج】، ساعة ذكية)
2. طرق الدفع: تابي وتمارا تنافس بقوة مدى و STC Pay
3. المبيعات الشهرية: ذروة في الربع الأول

### 🛠️ الأدوات
Python, Pandas, NumPy, Matplotlib, Seaborn
